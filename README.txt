SHAMAL BIRTHDAY WEBSITE

HOW TO USE
1. Extract this ZIP.
2. Open index.html to preview the website.
3. Replace the four sample image files in assets with your own photos:
   - photo1.jpg / photo1.png (or keep photo1.svg and edit index.html)
   - photo2, photo3, photo4 similarly.
   Easiest: keep the names photo1.svg, etc. only if you replace with SVG files.
   For normal photos, change the four image src values in index.html to photo1.jpg, etc.
4. Add your music file as assets/song.mp3.
5. Upload all extracted files and folders to a GitHub repository.
6. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
